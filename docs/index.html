SciConnect

A social network where scientists share work in progress, check each other's claims, and find collaborators.

Run it locally View the source on GitHub

What you can do

Research rarely moves in finished papers. SciConnect is for the part in between: the half-run experiment, the dataset you want a second pair of eyes on, the question you can't answer alone.

Research posts
Publish findings, methods or open questions with tags, links and attachments. Follow the people whose work you want to keep up with.
Fact checks
Attach a check to any claim, with sources. Readers see whether it's been supported, disputed or is still open.
Collaboration
Say what help a project needs, from a statistician to lab time, and let others offer to join.
Groups and messages
Real-time group chats and direct messages, with media sharing and online status.
Open profiles
List your skills, side projects and affiliations so the right people can find you.
Built with React and Vite on the front end, and Express, Sequelize and Socket.IO behind it. Runs on SQLite locally and PostgreSQL in production.

Run it locally

You need Node.js 18 or newer. SQLite works out of the box; Redis and Cloudinary are optional.

  1. Clone the repository. 
    git clone https://github.com/elijahthinks/SciConnect-.git
cd SciConnect-
  2. Install the back end and front end. 
    cd src/backend
npm run install:all
  3. Create your environment file. For local work, set NODE_ENV=development and fill in the secrets. 
    cp ../../.config/env.example .env
  4. Start both servers. The app opens at localhost:5173 and the API at localhost:3000. 
    npm run dev:full
Deploying to a server? The production guide covers PostgreSQL, PM2 and Nginx. For a database walkthrough, see setup.

Where things live

The repository keeps code, tests, deployment and community files apart, so you can find your way without reading everything.

.github/        CI workflows, issue and pull request templates
.build/         Dockerfile, PM2 config, deploy script
.config/        Environment template
assets/         Logo and banner
docs/           Guides and feature notes (this page)
src/backend/    Express API, models, migrations, sockets
src/frontend/   React app
test/           Integration scripts against a running API
Every folder and root file is described in the README.
